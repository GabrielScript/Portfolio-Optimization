**Gate: no arm passes.** None beats the max Sharpe rule, and none comes near the Composite. N 117 -> 121.

What the reading says:

- **PPO still holds equal weights, with either network.** With the reward, the episodes, the inputs and the
  universe repaired, both PPO arms end within 0.05 of a point of the equal-weight rule. The shared network did not
  change that at 30,240 decisions (its seeds' validation rewards differ by 0.02): a Gaussian of 0.37 on 160 to 280
  logits gives PPO no usable gradient at this budget. The defect list was real, but fixing it does not make PPO
  an allocator here.
- **The exact gradient does learn something.** The same shared network trained through the simulator makes 12.6%
  a year against 7.6% for equal weights on the same names, with a positive alpha that is not distinguishable from
  zero (t 0.9). It is below the max Sharpe rule and ten points below the Composite.
- **The Composite's score as an input adds nothing** (12.4%, a deeper drawdown). A network given the score and five
  price inputs does not rediscover "hold the 15 best scores": on five years of a window it fits the price inputs.
- v2's table ended where the older Composite curve ended; this one ends on 2026-10-16 with the current baseline,
  so the rules' rows differ from v2's (same cells, a longer span).
